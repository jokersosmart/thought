# AI 時代思考指南｜新舊內容整合過程報告

> 說明：以下是可審核的決策摘要與執行紀錄，不是模型的私有逐字思考鏈。它保留判斷依據、分流規則、證據與不確定性，方便日後修改或重新驗證。

## 1. 先用最新思考習慣定義問題

### 問對問題

- 現況：舊內容 01–45 已有問題式檔名；新內容 46–89 是新增逐字稿；思考習慣清單原有 76 項。
- 目標：建立一套不重複、可追溯、方便日後使用的「問題—主要習慣—逐字稿」結構。
- 限制：保留原有 76 項的編號與定義穩定性；檔名只能放一個主要習慣；不能因為名稱不同就重複新增概念。
- 範圍：處理根目錄 01–89、整合索引、新舊分析報告與思考習慣清單；不改動無關的決策資料庫內容。

### 目的

整合的目的不是讓清單項目越多越好，而是讓每個項目都能成為可辨識、可練習、可遷移到不同問題的思考習慣。

## 2. 拆解與比對流程

### 步驟一：建立資料範圍

把資料拆成三個層次：

1. 逐字稿文件：提供實際案例、方法與課程脈絡。
2. 思考習慣清單：作為正式名稱與定義的基準。
3. 索引與分析報告：記錄文件和習慣之間的對應關係。

### 步驟二：抽取新內容中的候選習慣

優先辨識逐字稿明確使用的標籤或課程主題，例如「問對問題」「限制條件」「演繹」「歸納」「自我覺察」與「創造參與」。再回頭檢查它們是否已存在於清單。

### 步驟三：做名稱正規化

不同名稱但底層能力相同時，採用清單中的正式名稱：

| 新內容用語 | 清單正式名稱 |
|---|---|
| 變量 | 變數控制 |
| 效用 | 效用理論 |
| 演繹 | 演繹推理 |
| 歸納 | 歸納推理 |
| 合理性 | 合理性評估 |
| 形塑行為 | 行為塑造 |
| 道德勇氣 | 倫理勇氣 |

### 步驟四：用差距分析決定是否新增

每個候選習慣都經過以下判斷：

1. 它是否有清楚不同於既有項目的核心問題？
2. 它是否能獨立應用，而不只是某個舊習慣的案例或技巧？
3. 它是否在新內容中反覆出現，或足以支撐一套獨立的操作檢查？
4. 若新增，是否會造成既有清單的重複或編號不穩定？

依此判斷，新內容中的大多數候選項目都能對應到原有 76 項；唯一真正形成獨立缺口的是「創造參與」。

### 步驟五：用歸納與演繹交叉檢查

- 歸納：從 46–89 的多個單元觀察反覆出現的主題，找出新內容的整體脈絡。
- 演繹：從「獨立、可重複使用、非同義重複」的新增規則，推導哪些項目應該留在既有清單、哪些項目可以新增。
- 合理性評估：檢查新增項目是否真的解釋了舊項目無法獨立說明的現象。

### 步驟六：為每份文件指定一個主要習慣

一份逐字稿可能同時涉及多個習慣，但檔名需要可讀且穩定，因此只選一個最能代表該篇主要問題與方法的習慣。其他次要涵蓋內容保留在逐字稿、索引脈絡與新舊分析報告中。

例如：

- 53「面對混亂問題時怎麼判斷該用哪種方法」→ `問對問題`
- 68「證據有限時怎麼一步步推導出可靠結論」→ `演繹推理`
- 81「如何讓大家願意參與而不是只是被要求配合」→ `創造參與`

## 3. 使用哪些最新思考習慣來檢查整合

| 思考習慣 | 在本次整合中的用途 |
|---|---|
| 問對問題 | 定義現況、目標、限制與範圍 |
| 拆解問題 | 將文件、標籤、清單、索引與驗證分開處理 |
| 系統描繪 | 看清逐字稿、清單、索引與決策資料庫的關係 |
| 差距分析 | 找出新內容真正超出原清單的能力 |
| 限制條件 | 保留原 76 項穩定性，並限制每個檔名只放一個主標籤 |
| 偏誤檢驗 | 避免因新內容較新、名稱較醒目就誤判為新習慣 |
| 可驗證性 | 用檔案數、編號、連結與時間戳檢查成果 |
| 科學學習法 | 把整合做成可回顧、可測試、可修正的學習系統 |
| 創造參與 | 保留使用者日後修正分類與補充定義的入口，而非一次封閉定案 |

## 4. 主要判斷與不確定性

- 「主要習慣」是分類用途，不代表一份逐字稿只談一個習慣。
- 某些課程單元同時涵蓋多項能力，檔名後綴是方便搜尋的主標籤，不是完整語意摘要。
- 「創造參與」已被定義為 AI 時代補充，未取代或重新編號原有 76 項。
- 未來若新增更多逐字稿，應先沿用既有名稱，再判斷是否真的出現新的獨立能力。
