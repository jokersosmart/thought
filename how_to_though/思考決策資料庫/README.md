# 思考決策資料庫

這個專案把 AI 時代思考指南的逐字稿與決策報告整理成可重複使用的問題處理知識庫。根目錄的 01–89 是問題式逐字稿與課程內容，這個資料夾則保留 01–45 的決策報告。每份報告不是單一標籤，而是由核心、輔助與隱性思考習慣組成的「組合拳」。

目前的思考習慣基準是 [思考習慣清單_v3](../思考習慣清單_v3.md)：原有 76 項，加上標示為「AI 時代補充」的第 77 項 `#創造參與`。這個專案目前是 Markdown 知識庫，不是已封裝、可自動啟用的 Skill；它可以作為未來 Skill 的內容來源。

## 如何使用

1. 先到[整合索引](../AI時代思考指南_全課程逐字稿索引.md)，選出最接近目前處境的問題。
2. 再到[思考習慣清單_v3](../思考習慣清單_v3.md)，確認該習慣的定義、使用時機與檢查清單。
3. 如果有對應的決策報告，先讀「一句話判斷」與「適用情境」。
4. 依「決策流程」逐步產出答案，不要跳過進入下一步的判準。
5. 用「常見誤用與停損條件」檢查是否需要修正或停止。
6. 若情境不同，從「跨領域遷移」找到可套用的結構，而不是照抄原案例。

## 用這套思考模式分析新問題

不需要先自己選思考習慣。描述問題時，可以直接說明情境、想處理的事情與目前卡住的地方；分析者再依照清單選擇最適合的習慣。

建議的分析順序是：

1. **問對問題**：整理初始狀態、目標狀態、障礙與限制、規模與範圍。
2. **選擇習慣**：指定一個主要習慣，必要時搭配一至三個輔助習慣。
3. **查找證據**：從逐字稿、決策報告或其他可靠資料找出相關依據。
4. **分析與行動**：說明判斷、假設、可能偏誤、下一步與驗證方法。
5. **回顧修正**：依結果更新對問題、方法與限制的理解。

可以使用以下提示開始對話：

> 請使用這個專案最新的《思考習慣清單_v3》分析我的問題。先整理初始狀態、目標狀態、障礙與限制、規模與範圍，再選出一個主要思考習慣與必要的輔助習慣。請參考相關逐字稿或決策報告，說明判斷依據、可能盲點、下一步行動，以及如何驗證是否真的改善。

每份文件的檔名只標示一個「主要思考習慣」，不代表該文件只涵蓋一個習慣；其他重疊內容請查看索引與[新舊內容重疊分析](../AI時代思考指南_新舊內容重疊分析.md)。

## 證據標記

- **明示**：逐字稿直接點名或清楚定義該思考習慣。
- **推論**：逐字稿實際使用了該習慣的操作，但沒有直接命名。
- **待驗證**：有合理跡象，但現有內容不足以確定。
- **一般策略**：有助於流程，但不屬於《思考習慣清單》的 77 個正式習慣（原有 76 項，加上 AI 時代補充 1 項）。

## 對話使用方式

描述問題時，至少提供「想達成的結果、目前限制、已知證據、可接受代價」。如果暫時說不完整，也可以先用自然語言描述，讓分析者協助補齊問題結構。

可使用以下提示：

> 請從思考決策資料庫找出與這個問題最相近的 1–3 份報告，告訴我核心、輔助與隱性思考習慣，依正確順序帶我完成決策，並指出還缺少哪些證據。

## 其他人如何使用

### 閱讀與手動使用

不需要安裝程式。可以直接開啟 [GitHub 儲存庫](https://github.com/jokersosmart/thought)，或下載／複製專案後閱讀索引與清單。

#### 下載 ZIP

適合不熟悉 Git 的使用者：

1. 開啟 GitHub 儲存庫。
2. 點選綠色的 **Code** 按鈕。
3. 選擇 **Download ZIP**。
4. 解壓縮後，先開啟根目錄的 `README.md`，再依序閱讀整合索引與 `思考習慣清單_v3.md`。

#### 使用 Git 複製

適合需要持續同步更新的使用者：

```bash
git clone https://github.com/jokersosmart/thought.git
```

複製完成後，進入 `thought/how_to_though` 資料夾，從 [整合索引](../AI時代思考指南_全課程逐字稿索引.md) 找到與問題最接近的內容，再查看[思考習慣清單](../思考習慣清單_v3.md)與相關報告。

如果只想讓 AI 協助分析問題，不需要一次提供所有逐字稿；先提供 `思考習慣清單_v3.md`，再提供最相關的 1–3 份逐字稿或決策報告即可。

建議從以下順序開始：

1. [AI 時代思考指南｜整合索引](../AI時代思考指南_全課程逐字稿索引.md)
2. [思考習慣清單_v3](../思考習慣清單_v3.md)
3. 與目前問題最接近的逐字稿或決策報告

### 交給 AI 使用

目前 GitHub 網址本身不會讓其他 AI 自動啟用這套思考模式。使用者需要把《思考習慣清單_v3》與相關逐字稿／報告提供給 AI，並要求它依照「問對問題」的四個元素分析。

### 更新知識庫

1. 把新的逐字稿放在根目錄，沿用 `NN_問題式標題_主要思考習慣.md` 命名規則。
2. 先比對《思考習慣清單_v3》的既有定義，再判斷是對應、重疊或真正新增。
3. 更新整合索引與新舊內容分析。
4. 若新增習慣，保留原有編號，並清楚標示來源與定義。
5. 用 Git commit / push 發布更新，其他人再執行 `git pull` 取得新版本。

## Skill 現況與未來封裝

這個儲存庫目前是知識庫，不是 Skill，因為尚未包含 `SKILL.md`。若要讓 Codex 或其他支援 Skill 的 AI 自動使用，建議新增：

```text
skills/
└─ thinking-decision-toolkit/
   ├─ SKILL.md
   └─ references/
      └─ 思考習慣清單_v3.md
```

`SKILL.md` 應該定義何時啟用、如何拆解問題、如何選擇主要與輔助習慣、如何引用證據，以及最後的輸出格式；逐字稿與清單則作為參考資料。封裝完成前，請把這個儲存庫視為唯一的知識來源，避免使用者各自維護不同版本的清單。
