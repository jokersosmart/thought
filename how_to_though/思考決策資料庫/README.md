# 思考決策資料庫

這個資料庫將 45 篇課程逐字稿轉換成可重複使用的問題處理流程。每份報告不是單一標籤，而是由核心、輔助與隱性思考習慣組成的「組合拳」。

## 課程逐字稿與整合索引

新增的 AI 時代思考指南逐字稿，以及根目錄 01–89 的問題式檔案總表，請見 [AI 時代思考指南｜整合索引](../AI時代思考指南_全課程逐字稿索引.md)。

## 如何使用

1. 從下方索引選出最接近目前處境的問題。
2. 先讀報告中的「一句話判斷」與「適用情境」。
3. 依「決策流程」逐步產出答案，不要跳過進入下一步的判準。
4. 用「常見誤用與停損條件」檢查是否需要修正或停止。
5. 若情境不同，從「跨領域遷移」找到可套用的結構，而不是照抄原案例。

## 證據標記

- **明示**：逐字稿直接點名或清楚定義該思考習慣。
- **推論**：逐字稿實際使用了該習慣的操作，但沒有直接命名。
- **待驗證**：有合理跡象，但現有內容不足以確定。
- **一般策略**：有助於流程，但不屬於《思考習慣清單》的 76 個正式習慣。

## 對話使用方式

描述問題時，至少提供「想達成的結果、目前限制、已知證據、可接受代價」。可使用以下提示：

> 請從思考決策資料庫找出與這個問題最相近的 1–3 份報告，告訴我核心、輔助與隱性思考習慣，依正確順序帶我完成決策，並指出還缺少哪些證據。
