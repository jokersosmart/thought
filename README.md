這是一套把問題式逐字稿、思考習慣與決策報告整理在一起的 Markdown 知識庫，目的是協助人或 AI 在面對問題時，先把問題定義清楚，再選擇適合的思考方法。

## 快速開始

1. 閱讀 [AI 時代思考指南｜整合索引](how_to_though/AI時代思考指南_全課程逐字稿索引.md)，依照你遇到的問題尋找相關內容。
2. 閱讀 [思考習慣清單_v3](how_to_though/思考習慣清單_v3.md)，確認習慣的定義、適用時機與檢查清單。
3. 需要具體決策流程時，查看 [思考決策資料庫 README](how_to_though/思考決策資料庫/README.md) 與對應的決策報告。

## 用這套思考模式分析問題

你不需要先知道該用哪個思考習慣。直接描述遇到的情境，並盡量提供：

- 想達成的結果
- 目前的限制
- 已知的證據
- 可以接受的代價

分析時先依照「問對問題」整理四個元素：

1. 初始狀態：現在實際發生什麼事？
2. 目標狀態：希望得到什麼具體結果？
3. 障礙與限制：什麼阻礙或條件不能忽略？
4. 規模與範圍：這次要處理到哪裡？

接著選出一個主要思考習慣，必要時搭配輔助習慣，並輸出判斷依據、可能盲點、下一步行動與驗證方式。

可以把以下提示詞提供給 AI：

> 請使用這個專案最新的《思考習慣清單_v3》分析我的問題。先整理初始狀態、目標狀態、障礙與限制、規模與範圍，再選出一個主要思考習慣與必要的輔助習慣。請參考相關逐字稿或決策報告，說明判斷依據、可能盲點、下一步行動，以及如何驗證是否真的改善。

## 如何取得與更新

這是 Markdown 知識庫，不需要安裝程式。可以直接在 GitHub 閱讀，也可以複製到本機：

```bash
git clone https://github.com/jokersosmart/thought.git
```

更新時執行：

```bash
git pull
```

新增內容時，請先更新根目錄逐字稿、思考習慣清單與整合索引，再檢查新舊重疊關係。檔名沿用：

```text
NN_問題式標題_主要思考習慣.md
```

## Skill 現況

目前這個儲存庫是知識庫，不是可自動啟用的 Skill，因為尚未包含 `SKILL.md`。GitHub 網址可以讓其他人取得內容，但不會讓其他 AI 自動套用這套思考模式；使用者需要把清單與相關文件提供給 AI，或另外將它封裝成 Skill。
